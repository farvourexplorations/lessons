The Big Question

What makes a rule a function?

Press B4 on a vending machine and you always get the same snack. Imagine a machine where B4 sometimes gives chips and sometimes gives a drink. You couldn't trust it. A function is a rule you can trust: each input gives exactly one output.

Your height depends on your age. Your phone bill depends on how much data you use. A ball's height depends on time. Some of these relationships make straight-line graphs and some make curves. How can you tell which is which, just from a table?

🧠 Warm-up — is it a function?

Different outputs can repeat. What can't happen is one input with two different outputs.

Discover the Vocabulary

📚 The language of functions

Click each word to reveal its meaning.

⚙️ Function ↔️ Input & Output 📏 Linear Function ⏱️ Rate of Change 🎯 Initial Value
Function — a rule that assigns each input exactly one output. Its graph passes the vertical line test.

y = 3x + 1 is a function; x² + y² = 25 is not.
Input & Output — the input (x) goes into the rule; the output (y) comes out. A function's graph is the set of all (input, output) pairs.

input 4 → rule "double it" → output 8
Linear Function — a function y = mx + b. Its graph is a straight line and its table has a constant rate of change.

A = s² (area of a square) is NOT linear.
Rate of Change — how much the output changes for each 1-unit change in input. For a linear function it's the slope m.

$4 per ticket → rate of change 4
Initial Value — the output when the input is 0. For a linear function it's the y-intercept b.

A $25 sign-up fee is the initial value.

Real-World Connections

Functions all around you 🌍

Any time one quantity determines another, you're looking at a function.

🎮

Video Games

Every frame, a game uses functions to turn time into a character's position on screen.

🌡️

Temperature

°F = 1.8 × °C + 32 is a linear function: rate 1.8, initial value 32.

📦

Shipping

Cost depends on weight. Each weight gives exactly one price.

⚽

Sports

A kicked ball's height over time is a nonlinear function: it curves up, then down.
