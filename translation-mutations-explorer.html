Phase 1 · Wonder

🔬 From Code to Protein — and What Goes Wrong

You've mastered how DNA becomes mRNA. Now the real action begins: translation turns that mRNA into a protein, and mutations explain why sometimes the protein comes out wrong — with enormous consequences.

Sickle cell disease is caused by a single letter change in the DNA — one nucleotide swapped for another. That single change alters one amino acid in hemoglobin, and the result is a devastating disease. How can one tiny change in a 3-billion-letter code cause so much harm?

✏️ Your Prediction (before we dig in)

Translation converts a series of codons (three-nucleotide mRNA sequences) into a chain of amino acids. The ribosome reads the codons, tRNAs bring the matching amino acids, and the chain grows until a stop codon signals the end. The result: a folded protein ready to work. If a mutation changes even one codon, the entire protein can be altered — or destroyed entirely.

🗝️ The Big Picture

Translation (10.3) happens at the ribosome in the cytoplasm. The ribosome reads mRNA three bases at a time (a codon), tRNA delivers the right amino acid, and a peptide bond locks it into the growing chain. Mutations (10.4) are changes to the DNA sequence — they can be point mutations (substitutions) or insertion/deletion mutations that shift the entire reading frame.

📖 Translation — Core Vocabulary

Tap each term to reveal its definition and packet connection (Q21–39). You must know these cold — the AP exam will test vocabulary and application.

Translation Ribosome Start Codon Stop Codon Anticodon Peptide Bond Polypeptide tRNA Role 3 Steps of Translation Genetic Code
Translation — The process of decoding an mRNA sequence into a chain of amino acids (a polypeptide). It occurs at the ribosome in the cytoplasm. Translation reads mRNA codons (three nucleotides at a time) and uses tRNA to deliver the matching amino acid. Q21, Q22.
Ribosome — The molecular machine that carries out translation. Made of rRNA + proteins. It has two subunits (large and small) that clamp around the mRNA. The ribosome holds the mRNA and tRNA in place and catalyzes peptide bond formation between amino acids. Q23, Q28.
Start Codon (AUG) — The codon that signals the beginning of translation. AUG always codes for methionine (Met) and serves as the initiation signal. Every protein begins with methionine (though it's sometimes removed later). Without a start codon, the ribosome cannot begin. Q24, Q25.
Stop Codons (UAA, UAG, UGA) — Three codons that signal the end of translation. They do not code for any amino acid — instead, when the ribosome reads one, it releases the finished polypeptide chain. There are three stop codons: UAA, UAG, UGA. Q26, Q27.
Anticodon — The three-nucleotide sequence on a tRNA molecule that is complementary and antiparallel to a specific mRNA codon. The anticodon ensures the correct amino acid is delivered during translation. Example: if mRNA codon = AUG, the anticodon on tRNA = UAC. Q29, Q30.
Peptide Bond — The covalent bond that links two amino acids together. The ribosome (specifically, the rRNA component) catalyzes the formation of peptide bonds as the polypeptide chain grows. Each new amino acid added extends the chain via a peptide bond. Q31, Q32.
Polypeptide — A chain of amino acids linked by peptide bonds. This is the direct product of translation. A polypeptide folds into a specific 3D shape to become a functional protein. The sequence of amino acids is determined by the mRNA codons. Q33.
tRNA (transfer RNA) — Acts as the "adapter" molecule in translation. Each tRNA carries one specific amino acid at one end, and its anticodon loop base-pairs with the matching mRNA codon. This match ensures the genetic code is faithfully translated — the right amino acid goes in the right place. Q29, Q34.
3 Steps of Translation — Initiation: ribosome assembles on mRNA at the start codon (AUG). Elongation: tRNAs deliver amino acids one by one; peptide bonds form; chain grows. Termination: ribosome reaches a stop codon; polypeptide is released. Q35, Q36, Q37.
The Genetic Code — The complete set of rules relating mRNA codons to amino acids. It is universal (same in almost all living things), redundant/degenerate (multiple codons can code for the same amino acid), and nearly unambiguous (each codon specifies only one amino acid). Q38, Q39.

🔄 Point Mutation (Substitution)

A point mutation is a change in a single nucleotide in the DNA sequence. In a substitution, one base is replaced by a different base (e.g., A→G). Point mutations affect only the codon they occur in — the reading frame is preserved, so codons before and after are unchanged. The effect depends on how the new codon translates.

📌 Q40: A point mutation changes a single nucleotide in the DNA sequence.
📌 Q41: The three types of point substitution mutations are: silent, missense, and nonsense.
📌 Q42: A substitution mutation replaces one base with another.

🤫 Silent Mutation

A silent mutation is a nucleotide substitution that does not change the amino acid coded for — because of the redundancy of the genetic code (multiple codons can code for the same amino acid). The protein produced is identical to the original. Silent mutations have no effect on phenotype.

📌 Q43: Example — CGA → CGG. Both code for Arginine (Arg). No amino acid change → silent mutation.
📌 Why does this happen? The genetic code is degenerate — 64 codons code for only 20 amino acids, so many amino acids have multiple synonymous codons.

🔀 Missense Mutation

A missense mutation is a substitution that changes the amino acid at that position in the protein. The protein is built with the wrong amino acid, which may alter the protein's shape, stability, or function — or it may have little effect if the substituted amino acid is chemically similar.

📌 Q44: Example — GAG → GUG (in sickle cell disease). This changes glutamic acid → valine in hemoglobin — one amino acid swap that distorts red blood cells.
📌 Q47: A missense mutation can still produce a functional protein if the new amino acid is similar in properties to the original.

🛑 Nonsense Mutation

A nonsense mutation is a substitution that converts a codon that coded for an amino acid into a premature stop codon (UAA, UAG, or UGA). Translation halts early, producing a shorter, usually non-functional protein. Nonsense mutations tend to be the most severe of the substitution types.

📌 Q45: A nonsense mutation creates a premature stop codon, truncating the protein early.
📌 Q48: This usually results in a non-functional protein because an essential portion was never made.

📐 Frameshift Mutation (Insertion / Deletion)

A frameshift mutation occurs when nucleotides are inserted or deleted from the DNA in a number that is not a multiple of three. This shifts the reading frame — all codons downstream of the mutation are now read differently, typically producing a completely different (and usually non-functional) amino acid sequence. Frameshifts are usually more damaging than point substitutions.

📌 Q46: Insertion or deletion of nucleotides causes a frameshift — the entire downstream reading frame shifts.
📌 Q49: An insertion of one base shifts the reading frame; inserting three bases does NOT cause a frameshift (it just adds one amino acid).
📌 Q50: Frameshift mutations typically affect all amino acids downstream of the mutation site.
