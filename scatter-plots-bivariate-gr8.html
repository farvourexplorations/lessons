The Big Question

Does one thing really go with another?

Ice-cream sales and sunburns both rise in summer. Does ice cream cause sunburn? Of course not, but the numbers still move together. Data with two variables can reveal real patterns, and also fool you if you're not careful.

Scientists, sports analysts and businesses all ask the same question: if I know one measurement, can I predict the other? A scatter plot and a well-placed line can answer that in seconds.

🧠 Warm-up — positive or negative association?

Positive: both go up together. Negative: as one goes up, the other goes down. Association is not the same as cause.

Discover the Vocabulary

📚 Words for two-variable data

Click each word to reveal its meaning.

🔵 Scatter Plot ↗️ Association ⭐ Outlier & Cluster 📏 Line of Best Fit 🧮 Two-Way Table
Scatter Plot — a graph of paired data (x, y). Each dot is one person or object measured twice.

Each dot = one student: (hours studied, test score)
Association — a pattern between two variables: positive, negative or none; linear or nonlinear; strong or weak.

Height and arm span: strong positive linear.
Outlier & Cluster — an outlier is a point far from the pattern. A cluster is a group of points bunched together.

One student who studied 1 hour but scored 98 is an outlier.
Line of Best Fit — a straight line that follows the trend, with points spread evenly above and below. Its slope and intercept have meaning in context.

score = 6 × hours + 52 → each extra hour ≈ 6 more points
Two-Way Table — counts for two categorical variables. Relative frequencies (percentages) of each row reveal association.

Grade × "has a curfew? yes / no"

Investigation 3 · 8.SP.A.4

🧮 Two-Way Tables

Some data is categories, not numbers. A two-way table counts both at once. To see if there's an association, compare row percentages: if the rows look very different, the variables are associated.
